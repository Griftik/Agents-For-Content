# Фабрика контента @neurostrategy

Цепочка агентов, которая исследует → создаёт → публикует контент на внешних
площадках → переливает трафик в Telegram ([@neurostrategy](https://t.me/neurostrategy)) →
мягко греет к продуктам экосистемы «Таланты».

> **Источник правды по архитектуре** — опорный документ на Google Drive
> «ФАБРИКА — схема агентов». Здесь — код и инфраструктура.
> **Правда по коду** — этот репозиторий. **Правда по данным** — Google Drive.

## Схема хранения (гибрид)

- **На сервере** (рядом с агентами) — «рабочие» данные: очередь публикаций,
  состояния постов, кэш, логи, локальные копии баз. Живут в `data/` (в git не
  попадают).
- **На Google Drive** — «ценные» данные: `posts_for_claude.json`, контент-план,
  дайджесты, метрики, база каналов-партнёров, конфиги стиля.
- **Синхронизация** (`core/drive_sync.py`): агент работает с быстрой локальной
  копией → по расписанию выгружает ценное на Drive. Последний записал — прав.

## Семь агентов

## Структура репозитория

```
core/                    общее ядро всех агентов
  config.py              единый конфиг (читает .env)
  logging_setup.py       единый формат логов
  drive_sync.py          синхронизация локальная копия ↔ Google Drive
agents/                  сами агенты (добавляются по шагам 1–7)
deploy/                  подъём и обслуживание сервера
  bootstrap.sh           идемпотентный подъём чистого VPS
  contentmaker.service   systemd-юнит бота (Шаг 1)
  analyst.service/.timer таймер Аналитика (Шаг 2)
data/                    рабочие данные (в git не попадают)
.env.example             шаблон секретов (реальный .env — только на сервере)
```

## 🔐 Секреты

Секреты **никогда** не попадают в git: `.env` живёт только на сервере,
`.gitignore` его исключает. В репозитории — только `.env.example` с
плейсхолдерами.

Перед первым запуском (обязательно):
- выпусти **свежий** токен бота у @BotFather (старый был зашит в коде — заменить);
- **перевыпусти** ключ OpenRouter (прежний засветился);
- смени пароли, которые лежали открытым текстом в общей папке на Drive.

## 🚀 Подъём сервера (Шаг 0)

**Хостинг.** Нужен VPS, который (1) оплачивается из РФ и (2) имеет
**зарубежный** IP — некоторые AI-сервисы (OpenRouter, иногда Google) могут
ограничивать российские адреса. Рекомендация: **aeza**, локация ЕС
(Германия / Нидерланды / Финляндия), оплата картой РФ / СБП / крипта. Запасные:
PQ.Hosting, VDSina. Менее подходят для этого кейса: Selectel / Yandex Cloud /
Cloud.ru (обычно только РФ-IP).

**Конфигурация:** 2 vCPU / 2–4 ГБ RAM / 40+ ГБ NVMe, **Ubuntu 24.04 LTS**.
Бот лёгкий, тяжёлой локальной обработки нет — GPU не нужен.

**Шаги:**

```bash
# 3. Секреты:

# 4. (Шаг 1) Служба бота — см. deploy/contentmaker.service
```
