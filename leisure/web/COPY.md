# Тексты приложения «Досуг» (бывший бот «Планировщик досуга»)

**Поворот (25.10.2026):** Telegram снят целиком, продукт — веб-приложение на экране телефона (`docs/PIVOT-PWA.md`). Разделы 1–8 — тексты бота; что из них снято, что переиспользуется, а что заменено, сказано в таблице «Статус текстов после поворота» в разделе 10. Новые тексты приложения — разделы 9 и 10. Экраны — `FLOW-APP.md`, `FLOW-INVITE.md`, `FLOW-ONBOARDING.md`.

Готовые строки для переноса в код один в один. Тон прототипа: ты-обращение, короткие фразы, без восклицаний, без эмодзи. Источник нынешних текстов — `bot/onboarding.py`, `bot/keyboards.py`, `bot/commands.py`, `bot/decisions.py`, `worker/messages.py`. Схема экранов и callback — `FLOW-ONBOARDING.md`.

## Правила текста

- Разметка — HTML Telegram (`<b>`, `<i>`), как сейчас. Всё, что подставляется из данных (название, площадка, имя), проходит через `html.escape`.
- Подстановки в фигурных скобках: `{title}`, `{n}`. Слова с числом склоняются функцией `_plural` (событие / события / событий, направление / направления / направлений).
- Слова: «подборка» (не «дайджест»; «Весь дайджест» остаётся только как название кнопки на веб-страницу), «направления» (в интерфейсе вместо «категории»), «ценности», «план». Статусы: «Иду», «Может быть», «Интересно», «Мимо» — всегда с заглавной на кнопках, в середине фразы в кавычках-ёлочках.
- Дата: «24 окт» на карточке, «24 октября» в заголовках. Время: «13:00–15:00» (длинное тире), «17:00 и 20:00». Процент: «91 %» с неразрывным пробелом. Стрелки `→` и `←`, галочка `✓` и точка `●` — текстовые знаки, не эмодзи.
- Кнопки пользователя не склоняют по роду: «Принять и начать», «Не получилось пойти», а не «Согласен», «Не пошёл». Бот говорит о себе в мужском роде, как сейчас («подобрал», «запомнил»).
- Тост (ответ на нажатие) — до 200 знаков, не повторяет подпись кнопки, не извиняется без причины.
- Обещание «напомню» в тостах и приветствии допустимо только пока воркер его исполняет (Д2). Пока не исправлено, использовать варианты «без напоминания», отмеченные ниже.

## 1. Первый контакт (снято: бот)

### T-HELLO — приветствие и согласие
Где: `bot/onboarding.py`, константа `HELLO`, функция `start` (и `reset`).
Чем плох нынешний: восклицание «Привет!»; «рубрики афиши» — внутренняя речь; «три минуты» не выполняется (медиана 33 нажатия); не сказано, что человек получит после ответов; согласие смешано с рекламой; не названо право удалить данные; «Согласен, поехали» не говорит, на что согласие и что дальше.

```
Я подбираю события на выходные под то, что для тебя важно. Каждый четверг в 19:00 по твоему времени присылаю 5–7 карточек и пишу, почему каждая подходит именно тебе.

Чтобы собрать первую подборку, нужны два ответа: пять главных ценностей и интересы. Это около двух минут. Остальное можно уточнить позже.

Я сохраню твой Telegram id, имя и ответы. Данные хранятся в России и нужны только для подборки. Удалить их можно в любой момент: /delete.
```
Кнопки: `Политика обработки данных` (url) · `Принять и начать` (`ob:consent`).

### T-RESET — /reset
Где: `bot/onboarding.py`, функция `reset`.
Чем плох: заново показывает согласие и всё приветствие, хотя согласие уже дано; не говорит, что будет с решениями.
Строка (сразу экран Э1, согласие не повторяется; `consent_at` уже есть):
```
Настроим заново. Новые ответы заменят прежние, а решения по событиям останутся.
```
Эта строка стоит над текстом `T-ONB-VALUES` в том же сообщении.

### T-START-AGAIN — /start у настроенного профиля
Где: `bot/onboarding.py`, функция `start`.
Чем плох: «С возвращением» плюс перечень из четырёх команд в одной строке, без главного действия.
```
Профиль уже настроен. Подборка на эти выходные: /digest. Твой план: /plan. Поменять ответы: /profile.
```

### T-NOT-READY — команда до настройки
Где: `bot/commands.py`, константа `NOT_READY`.
Чем плох: приказ без причины и без оценки усилий.
```
Сначала короткая настройка. Нажми /start, это около двух минут.
```

## 2. Онбординг

### T-ONB-VALUES — Шаг 1 из 2
Где: `bot/onboarding.py`, функции `consent`, `pick_value`; `bot/keyboards.py`, `values_pick_keyboard`.
Чем плох: «Шаг 1 из 5» стоит на девяти экранах подряд; «Выбери пять» без объяснения, зачем; счётчик живёт в кнопке, которая ничего не делает; на «Уже пять» нет пути вперёд.
Текст (строка `Выбрано` обновляется при каждом нажатии):
```
<b>Шаг 1 из 2 · Что для тебя важно</b>
Выбери пять ценностей. Подборка пойдёт от них, а не от рубрик афиши. Как отметишь пятую, сразу перейду к интересам. Кнопки идут группами: познание, люди, тело и чувства, смысл.

Выбрано {n} из 5{: список через запятую}
```
Пятая ценность при первом прохождении сразу открывает «Шаг 2 из 2»: текста «Выбрано 5 из 5» и кнопки «Дальше» тогда нет. Если человек вернулся на этот экран по «← Назад» (пять уже выбраны) или снял одну ценность и выбрал снова, при пяти текст такой: `Выбрано 5 из 5: {список}. Нажми «Дальше» или поменяй выбор.`
Кнопки нижнего ряда: `← Назад` (`ob:go:hi`) · `Дальше →` (`ob:go:i`, только при пяти и открытом экране).

### T-ONB-INTERESTS — Шаг 2 из 2
Где: `bot/onboarding.py`, функция `_ask_weight` (текст), `interest_cycle`; `bot/keyboards.py`, `interests_keyboard`.
Чем плох: «нажимай, чтобы поменять (— не показывать · иногда · интересно · в первую очередь)» — цикл из четырёх состояний описан в скобках; 19 кнопок в столбик; непонятно, что будет с непоказанными направлениями. ```

## 3. Подборка

### T-DIGEST-HEAD-FIRST — заголовок первой подборки
Где: `worker/messages.py`, функция `digest_header` (вызов из `bot/onboarding.py`, `_first_digest`).
Чем плох нынешний: пишет «подобрал {n} событие под тебя» без причины; обещание «напомню в субботу утром» выполняется лишь для субботы (Д2); нет кнопок.
```
<b>Выходные {title}</b>
{name, }вот первая подборка: {n} {событие/события/событий} под твои ценности. Отметь, что подходит, и следующие станут точнее.

Время, бюджет и эстетику можно уточнить кнопкой ниже.
```
Кнопки: `Весь дайджест` (url) · `Мой план` (`pl:s`) · `Уточнить под себя` (`ob:go:s`).

### T-DIGEST-HEAD — заголовок еженедельной подборки
Где: `worker/messages.py`, функция `digest_header`.
```
<b>Выходные {title}</b>
{name, }подобрал {n} {событие/события/событий} под тебя. Отмечай, что подходит: «Иду» попадёт в план.
```
Если воркер напоминает в день события (Д2 исправлен), добавить: ` Утром в этот день напомню.`
Кнопки: `Весь дайджест` (url) · `Мой план` (`pl:s`).
Если у профиля ещё не открывалось меню «Уточнить» и это вторая подборка, добавляется третья кнопка `Уточнить под себя`, один раз.

Где: `worker/messages.py`, `digest_header` (новая ветка, У7).
Чем плох нынешний: ветки нет, подборка выглядит просто короткой.

```
<b>Выходные {title}</b>
На эти выходные подходящего немного: {n} {событие/события/событий}. Остальное в афише слабо совпало с твоими интересами. Шире можно посмотреть в «Весь дайджест» или добавить направления в /profile.
```

Кнопки: `Весь дайджест` · `Мой план`.

### T-DIGEST-EMPTY — пустая подборка
Где: `bot/onboarding.py`, `_finish` («На эти выходные под твой профиль пока ничего не нашлось…»); `bot/commands.py`, `digest` («пока пусто. Загляни в /profile — может, стоит включить ещё категории»); `worker/schedules.py` — воркер сейчас молчит (У7).
Чем плох нынешний: в рассылке человек не получает ничего; в двух других местах разные тексты и «категории».
```
<b>Выходные {title}</b>
На эти выходные под твой профиль ничего не нашлось. Чаще всего в афише мало событий по твоим направлениям. Загляни в «Весь дайджест» или добавь направления в /profile. Следующая подборка придёт в четверг.
```
Кнопки: `Весь дайджест` (url) · `Мои интересы` (`ob:go:i`, режим профиля).
Вариант, если есть события «на горизонте» (после заголовка идут карточки горизонта):
```
<b>Выходные {title}</b>
На эти выходные под твой профиль ничего не нашлось. Зато есть {n} {событие/события/событий} позже: ниже ближайшие.
```

### T-CARD — подпись карточки
Где: `worker/messages.py`, функция `card_text`.
Чем плох нынешний: день и время склеены запятыми («Суббота, 24 окт, 13:00»); время — сырой текст источника, с несколькими датами сразу (У8); не видно прежнего ответа на повторной карточке (У11); «Совпадение 91%» без пробела.
Шаблон (строки без данных пропускаются):
```
<b>{title}</b>
{День, дата} · {время этого дня}
{площадка} · м. {метро}
{Бесплатно | цена}
<i>Почему тебе:</i> {причина · причина · причина}
{подсказка ядра}
<i>Но:</i> {минус, минус}
Совпадение {score} %
```
Дополнительные строки:

| Условие | Строка и место |
|---|---|
| Событие в несколько дней уикенда | после строки дня: `Ещё: {Вс, 25 окт}` — остальные дни, на которые есть расписание |
| Время выбранного дня разобрать нельзя | в строке дня только `{День, дата}`, а после площадки: `Расписание: {сырой текст источника}` |
| Карточка прислана повторно или после правки, решение есть | последняя строка: `Прежний ответ: {иду, суббота}`. Статусы строчными: иду, может быть, интересно, мимо; день только у «иду» и «может быть» с днём |
| У события у бота нет ссылки | кнопка «Подробнее» ведёт на страницу события в вебе (как сейчас) |

Кнопки (подписи): ряд дня `Пт` · `Сб` · `Вс` (только дни события, у выбранного префикс `● `); решения `Иду` · `Может быть` · `Интересно` · `Мимо` (у выбранного префикс `● `); ссылки `Подробнее` · `Другу`.

### T-TOASTS — тосты на кнопки карточки
Где: `bot/decisions.py`, словарь `TOASTS` и обработчик `on_card_button`.
Чем плох нынешний набор: «В плане ✓ Напомню в субботу утром.» обещает то, чего воркер не делает по воскресеньям и пятницам (Д2); «Понял. Почему мимо? Это поможет подбирать точнее.» похоже на обязательный вопрос (У6); «Спасибо! Это лучше всего учит подборку.» с восклицанием и внутренней кухней; «Событие уже убрали из базы» — «база» читателю ни о чём; «Что-то пошло не так» не говорит, что делать.

| Событие | Строка |
|---|---|
| Иду | `В плане: {суббота, 24 окт}.` Если воркер напомнит в этот день (Д2): `В плане: {суббота, 24 окт}. Напомню утром.` |
| Может быть | `Оставил в «может быть». Позже можно поменять.` |
| Интересно | `Запомнил. Буду показывать похожее.` |
| Мимо | `Понял, больше не покажу. Причину можно выбрать ниже, это необязательно.` |
| Причина выбрана | `Учту.` |
| Выбор дня, решение ещё не принято | `Показываю {суббота, 24 окт}.` |
| Выбор дня при «Иду» | `Перенёс в план на {воскресенье, 25 окт}.` |
| Не получилось пойти / Убрать из плана | `Убрал из плана.` |
| Оценка | `Оценка {n} из 5.` |
| Оценка изменена | `Оценка изменена: {n} из 5.` |
| Событие удалено из афиши | `Этого события уже нет в афише. Остальные: /digest.` |
| Ошибка сохранения | `Не удалось сохранить ответ. Нажми ещё раз.` |
| Повторное нажатие той же кнопки | без текста (Д7: `answerCallbackQuery` без сообщения) |

«Причина выбрана» заменяет «Спасибо, учту.» и «Ок.»; кнопка «Без причины» не нужна: можно просто не выбирать.

### T-REASONS — подписи причин «мимо»
Где: `bot/keyboards.py`, `reasons_keyboard`; `core/catalog.py`, `REASONS`.
Чем плох: подписи с маленькой буквы; семь кнопок и 4 ряда (У6); «Уже был», «Не то время» и «Не та компания» прятались за «Ещё…», и 9 из 25 выбранных причин (36 %) требовали второго нажатия (отчёт 2, У4).
Подписи кнопок (значения в данных не меняются): `Не моё` · `Дорого` · `Далеко` · `Уже был` · `Не то время` (данные: «не в это время») · `Не та компания`. Первый ряд: `Не моё` · `Дорого` · `Далеко` · `Уже был`; ниже отдельным рядом `Ещё…` заменяет причины на оставшиеся две: `Не то время` · `Не та компания`.

### T-NUDGE-BUDGET — подсказка про «Уточнить» после второго «Дорого»
Где: `bot/decisions.py`, обработчик причины «мимо» (`r:2:<id>`); новое сообщение под карточкой, один раз на профиль, только если бюджет «Не важно» (У3 отчёта 2; условия — FLOW-ONBOARDING.md, раздел «Подсказка про «Уточнить»»).
Чем плох прежний порядок: никакой подсказки не было, человек повторял «Мимо — дорого» и оставался с бюджетом «без ограничения».
```
Уже второй раз «Мимо» из-за цены. Задай потолок в «Уточнить под себя», и дорогое уйдёт ниже в подборке.
```
Кнопка: `Уточнить под себя` (`ob:go:s`). Откладывать не нужно: кнопки «Не сейчас» нет.

## 4. План

### T-PLAN-HEAD — /plan, обзор
Где: `bot/commands.py`, функция `plan` (`<pre>` из `plan['text']`).
Чем плох нынешний: моноширинный блок, строки до 400 знаков не переносятся и уходят за экран (У12); внутри блока нельзя выделить заголовки; эмодзи «⚠️» в карточках.
Формат — обычный текст HTML, строки переносятся:
```
<b>План · {23–25 октября}</b>
{n} {событие/события/событий} в плане{, одно пересечение}.

<b>Суббота, 24 окт</b>
13:00–15:00 · «Карманный онгон»: вырезать деревянного духа-хранителя
19:00 · Probka Wines на Малой Никитской (может быть)

<b>Воскресенье, 25 окт</b>
11:00–17:00 · Конференция «ОТЛЁТ!»

<b>Дальше</b>
до 29 ноября · Фотобиеннале в МАММ: Роджер Баллен
```
Правила: заголовок дня только если в нём есть события; сначала «Иду» по времени, затем «Может быть» с пометкой в скобках; без адресов (они в карточках); время дня берётся функцией `time_for_day`, при невозможности разобрать строка начинается с названия.
Кнопка под обзором: `Отправить план` (url `t.me/share`, текст плана — как сейчас `plan['text']`).

### T-PLAN-EMPTY — план пуст
Где: `bot/commands.py`, функция `plan`.
Чем плох: «План на 23–25 октября пока пуст. Отметь «Иду» в подборке: /digest» — «План на 23–25 октября» читается как заголовок.
```
В плане на {23–25 октября} пока ничего. Отметь «Иду» у событий в подборке, и они появятся здесь: /digest.
```

### T-PLAN-CARD — событие в /plan
Где: `bot/commands.py`, функция `plan`; `worker/messages.py`, `plan_item_keyboard`.
Чем плох: в карточке только название и «⚠️ пересекается по времени», без времени, площадки и дня.
```
<b>{title}</b>
{Суббота, 24 окт} · {13:00–15:00}
{площадка, адрес} · м. {метро}
Пересекается по времени с «{другое событие}».
```
Последняя строка только при пересечении; если название второго события недоступно: `Пересекается по времени.` Не больше шести карточек; при большем числе под последней кнопка `Показать остальные ({n})`.
Кнопки: `Google Календарь` · `Outlook` / `Другу` · `Убрать из плана` (`d:p:<id>`).

### T-PLAN-TODAY — «План на сегодня»
Где: `worker/messages.py`, функция `plan_today_text`.
Чем плох нынешний: маркеры «•» и двойной отступ, сырой текст расписания (У8: 10 % строк плана с несколькими датами), эмодзи «⚠️».
```
<b>План на сегодня · {суббота, 24 окт}</b>

<b>{title}</b>
{13:00–15:00} · {площадка, адрес}
Пересекается по времени с «{другое событие}».

<b>{title}</b>
{19:00} · {площадка, адрес}

Хорошего дня. Завтра спрошу, как прошло.
```
Если время дня определить нельзя: строка `Время уточни на странице события · {площадка, адрес}`.

### T-HOW — «Как прошло?»
Где: `worker/messages.py`, функции `how_was_it_text`, `rating_keyboard`; `bot/decisions.py`, обработка оценки.
Чем плох нынешний: нет дня события и не сказано, о чём речь, если событий несколько; «это лучше всего учит подборку» — довод в пользу продукта, а не человека; «Спасибо!» с восклицанием; звёзды «★★★» как подписи не читаются скринридером; нет выхода для тех, кто не пошёл (оценили 34 % из 129 запросов).
```
<b>Как прошло?</b>
«{title}», {суббота, 24 окт}.
Оцени от 1 до 5: по оценкам я подбираю точнее.
```
Кнопки: `1 ★` · `2 ★` · `3 ★` · `4 ★` · `5 ★` / `Не получилось пойти` (`d:p:<id>`). После оценки у выбранной префикс `● `, остальные остаются нажимаемыми; тост из T-TOASTS.

## 5. Команды (снято: бот)

### T-HELP — /help
Где: `bot/commands.py`, функция `help_cmd`.
Чем плох: команды без объяснения, как они связаны; расписание одним длинным предложением.
```
<b>Что я умею</b>
/digest — подборка на ближайшие выходные
/plan — твой план
/profile — что я о тебе знаю и как это поменять
/reset — пройти настройку заново
/delete — удалить мои данные

<b>По расписанию</b>
Четверг, 19:00 — подборка на выходные.
Суббота, утро — план на день.
Понедельник — вопрос, как прошло.
```

### T-PROFILE — /profile
Где: `bot/commands.py`, функции `profile_text`, `profile`.
Чем плох нынешний: поля через запятую без подписей («любая, день, вечер, бюджет без ограничения»); отдельно «Не показываю» и «В первую очередь» без заголовка; ссылка на веб-страницу, которой пока нет; правка только через /reset с самого начала (У4); пустой «Что я узнал о тебе» без объяснения.
```
<b>Твой профиль</b>

<b>Главные ценности</b>
{пять через запятую}

<b>Направления</b>
В первую очередь: {список или «пока нет»}
Не показываю: {список или «ничего»}

<b>Параметры</b>
Время: {день, вечер}
Бюджет: {не важен | до 1 000 ₽ | до 2 500 ₽ | до 5 000 ₽}
Эстетика: {важна | не принципиальна}

<b>Что я узнал о тебе</b>
{learned_text}
```
Пустое `learned_text` (T-PROFILE-LEARNED-EMPTY): `Пока мало ответов. Отметь несколько событий в подборке, и здесь появится, что тебе нравится.`
Кнопки: `Ценности` (`ob:go:v`) · `Интересы` (`ob:go:i`) / `Бюджет, эстетика, время` (`ob:go:s`) / `Открыть в вебе` (url, пока страницы нет — не показывать).
В режиме профиля главная кнопка Э2 — `Сохранить` вместо `Показать подборку →`, а `← Назад` ведёт в профиль.

### T-PROFILE-SAVED — после сохранения из профиля
```
Сохранил. Новая подборка придёт в четверг, а сейчас её можно собрать: /digest.
```

### T-DELETE — /delete
Где: `bot/commands.py`, функции `delete_cmd`, `delete_yes`, `delete_no`.
Чем плох нынешний: «Да, удалить всё» / «Отмена» — «Отмена» отменяет вопрос или удаление, неясно; «Готово» без пояснения, что осталось; после удаления нажатие на старую кнопку воссоздаёт профиль (Д3).
```
Удалить профиль, все решения и подборки? Это отзыв согласия на обработку данных. Восстановить будет нельзя, подборки приходить перестанут.
```
Кнопки: `Удалить всё` (`del:yes`) · `Оставить` (`del:no`).
После удаления: `Данные удалены. Если захочешь вернуться, нажми /start.` Профиля не было: `Профиля уже нет.` После «Оставить»: `Ничего не удалил.`

## 6. Исключения (снято: бот)

### T-STALE — устаревший экран
Где: новый общий обработчик `callback_query` в `bot/main.py` (Д12, Д3).
Чем плох нынешний: бот молчит, на кнопке бесконечная загрузка.
Тост (без `show_alert`):
```
Этот экран устарел. Открой актуальный: /start.
```
Если профиль удалён (Д3):
```
Профиля больше нет. Чтобы начать заново, нажми /start.
```

### T-TEXT-ANY — свободный текст вне заметки
Где: новый общий `message`-обработчик, регистрируется последним (У10, Д13).
Чем плох нынешний: бот молчит.
```
Я понимаю кнопки и команды, а обычный текст пока нет. Подборка: /digest, план: /plan, профиль: /profile, все команды: /help.
```
Неизвестная команда: `Такой команды нет. Список: /help.`

### T-TEXT-ONB — текст на шаге с кнопками
Где: тот же обработчик, когда профиль не завершён.
```
Здесь нужно нажать кнопку под сообщением. Если оно потерялось, нажми /start, и я покажу этот шаг снова.
```

## 7. Уточнение после подборки (меню бота снято; поля переехали в «Профиль»)

### T-SETUP — меню
Где: новый экран; заменяет цепочку `company → times → budget → aesthetics → areas → notes` в `bot/onboarding.py`.
```
<b>Уточнить под себя</b>
Необязательно: подборка уже собрана по ценностям, интересам и бюджету. Эстетика и время меняют состав, бюджет можно поменять. То же самое есть в /profile.
```
Кнопки: `Бюджет · {не важен | до 1 000 ₽ | до 2 500 ₽ | до 5 000 ₽}` · `Эстетика · {важна | не принципиальна}` · `Время · {день, вечер}` · `Пересобрать подборку` (если менялось) · `Готово`. Пункта «Заметка» нет: он вернётся вместе с LLM-разбором заметки, пока она подборку не меняет (T-SETUP-NOTE сохранён ниже).

### T-SETUP-BUDGET
Где: `bot/onboarding.py`, функция `times_next` (вопрос «Бюджет на одно событие?»); `bot/keyboards.py`, `BUDGETS`.
Чем плох: вопрос без объяснения последствий. Первый раз бюджет теперь задаётся на «Шаге 2 из 2» (T-ONB-BUDGET); здесь его меняют позже.

```
Более дорогие события окажутся ниже в подборке.
```
Кнопки: `Не важно` · `до 1 000 ₽` · `до 2 500 ₽` · `до 5 000 ₽` / `← Назад`. Значения те же, что в строке на «Шаге 2 из 2»; `●` у текущего.

### T-SETUP-AEST
Где: `bot/onboarding.py`, `budget` («Красота места и формата для тебя обязательна?»).
Чем плох: «обязательна» звучит как фильтр, а это вес.
```
<b>Красота места и формата</b>
Если важна, я подниму события с высокой оценкой эстетики.
```
Кнопки: `Да, важна` · `Не принципиально` / `← Назад`.

### T-SETUP-TIMES
Где: `bot/onboarding.py`, `company` («Когда тебе удобнее? Можно несколько.»).

```
<b>Когда тебе удобно</b>
Можно несколько. Если ничего не выбрать, возьму день и вечер.
```
Кнопки: `Утро` · `День` · `Вечер` · `Ночь` (у выбранных `✓ `) / `Готово` · `← Назад`. «Готово» и «Назад» ведут в меню; пустой выбор сохраняется как день и вечер.

### T-SETUP-COMPANY (скрыт, пока Д4 открыт)
Где: `bot/onboarding.py`, `interests_next` («Шаг 3 из 5. С кем ты обычно ходишь?»).
```
<b>С кем ты обычно ходишь</b>
```

### T-SETUP-AREAS (скрыт, пока Д4 открыт)
Где: `bot/onboarding.py`, `aesthetics` («Куда готов ехать?»).

```
<b>Куда ты готов ехать</b>
Дальние площадки будут реже.
```
Кнопки: `Центр` · `Любой район` · `Свой округ` / `← Назад`.

### T-SETUP-NOTE — заметка (скрыта: в меню и в /profile нет пункта до LLM-разбора)
Где: `bot/onboarding.py`, `areas` («Шаг 4 из 5. Напиши пару слов…»), `notes_text`.
Чем плох: заметка попадала в цепочку обязательных шагов, а на подборку не влияет (Д4); команда /help на этом шаге принималась за текст (Д13).

```
Напиши пару слов одним сообщением. Например: «Надоели бары, хочу в стеклодувную мастерскую». Я запишу это в профиль. Пока заметка не меняет подборку: я собираю её по ценностям и интересам.
```

```

```
и меню открывается заново (правка исходного сообщения меню не нужна: бот присылает меню новым сообщением под ответом).

Где: `POST /api/invites`, поле `share_text`; показывается в окне «Позвать друга» на карточке после «Иду» и в плане.
Чем плох прежний «Другу»: ссылка на событие без личной подписи, друг не понимает, зачем ему её прислали.
Простой текст, первое лицо, первая строка без названия сервиса. Целиком не длиннее 300 знаков вместе со ссылкой:
```
Иду на «{title}»: {суббота, 24 окт}, {13:00–15:00}, {площадка}. {why_fit_hint}
Пойдёшь со мной? {ссылка}
```
Правила: `{why_fit_hint}` берётся из описания события и обрезается до первого предложения и 70 знаков; при пустом значении строка пропускается вместе с точкой. `{площадка}` без адреса, до 40 знаков. Если вместе со ссылкой выходит больше 300 знаков, сначала обрезается `{why_fit_hint}`, затем `{title}` до 59 знаков и `…`. Ссылка: `<домен>/e/<slug>?inv=<код>`; её длина зависит от домена и слага, поэтому предел проверяется после подстановки.
Пример (около 190 знаков при домене `leisure.example`): `Иду на «Карманный онгон»: вырезать деревянного духа-хранителя: суббота, 24 окт, 13:00–15:00, Ателье ГЭС-2. Вырезаешь сам, мастер рядом.` и ниже `Пойдёшь со мной? https://leisure.example/e/karmannyj-ongon?inv=k3m9x2ab`.
Окно «Позвать друга»: заголовок `Позвать друга`, ниже текст приглашения, кнопки `Поделиться` (системное окно, Web Share API) · `Скопировать` (запасной вариант, `T-INVITE-COPIED`).

### T-INVITE-CARD — шапка приглашения над страницей события
Где: страница события `/e/[slug]` с кодом приглашения `?inv=<код>`.
Шапка, три строки:
```
Приглашение
{Имя} зовёт тебя
{Суббота, 24 окт} · {13:00–15:00}
```
Если пригласивший скрыл имя (`T-SETUP-NAME`): `Друг зовёт тебя`. Если пригласивший удалил данные: `Тебя зовут на событие` (`T-INVITE-GONE`), строка с днём остаётся. Строка при прежнем ответе друга: `Прежний ответ: иду, суббота`.
Кнопки: `Иду вместе` · `Может быть` · `Другие выходные под меня`.
Подпись под кнопками, если гостевого аккаунта ещё нет, — `T-INVITE-CONSENT`.

### T-INVITE-CONSENT — галочка согласия на странице приглашения
Подпись к `input type="checkbox"`; слова «политике обработки данных» — ссылка на `/policy` (обязательна):
```
Даю согласие на обработку моих ответов и решений, чтобы записать меня в план и подбирать события. Данные хранятся в России. Подробнее в политике обработки данных.
```
Цели те же, что в `T-APP-CONSENT` (раздел 10), только короче. Строка под галочкой: `Согласие можно отозвать в любой момент: «Удалить мои данные» в профиле.`

### T-INVITE-CONSENT-NEED — кнопка нажата без галочки
Выбор («Иду вместе» или «Может быть») запоминается и записывается сразу, как только отмечена галочка. Сообщение у галочки, `role="alert"`:
```
Отметь согласие, и я запишу твой выбор.
```

### T-INVITE-AUTH-FAIL — гостевой аккаунт не создался
Запрос `POST /api/session` не прошёл (`role="alert"`), выбор на странице остаётся:
```
Не получилось начать. Обнови страницу и попробуй ещё раз.
```

### T-INVITE-DONE — «Вы идёте вместе»
```
Вы идёте вместе
«{title}», {суббота, 24 окт}, {13:00–15:00}.
{Имя} увидит, что ты идёшь.
```
Если имя скрыто: `Друг увидит, что ты идёшь.` Вариант «может быть» (без календаря и без просьбы об уведомлениях):
```
Записано в «может быть»
«{title}», {суббота, 24 окт}.
{Имя} об этом не узнает. Передумать можно в плане.
```
Кнопки: `Добавить в календарь` (Google Календарь · Outlook · .ics) · `Мой план`. Ниже блок `T-INVITE-OFFER`.

### Короткие строки страницы приглашения и онбординга
Строки уже стоят в `webapp/src/components/InviteFlow.tsx` и `Onboarding.tsx`; здесь они закреплены за именами, дальше правятся только тут.

### T-INVITE-PENDING — запись идёт
Строка статуса после отправки решения, `role="status"`:
```
Записываю…
```

### T-INVITE-SAVE-FAIL — запись не удалась
Сервис недоступен или ответил ошибкой, выбор на странице остаётся (`role="alert"`):
```
Не получилось записать. Попробуй ещё раз.
```

### T-INVITE-UNAVAILABLE — событие стало недоступным при записи
Ответ `410` на запись: событие сняли, пока человек выбирал. Слово «Подборке» — ссылка на `/digest` (`role="alert"`):
```
Это событие уже недоступно. Другие выходные ждут в «Подборке».
```

### T-INVITE-DONE-GONE — «Ты идёшь» без имени пригласившего
Вариант `T-INVITE-DONE`, когда пригласивший удалил данные: слова «вместе» нет, о пригласившем ничего не сообщается.
```
Ты идёшь
«{title}», {суббота, 24 окт}, {13:00–15:00}.
Событие в твоём плане.
```
Вариант «может быть» (заголовок «Записано в «может быть»»): `Передумать можно в плане.` То же при неизвестном имени у «может быть».

### T-INVITE-ONB-STEP1 — «Шаг 1 из 2»
```
Шаг 1 из 2
Что для тебя важно
Выбери пять главных ценностей из {n}. Остальные тоже учту, но слабее.
```
Ошибка выбора: `Нужно выбрать ровно {5}.` (`role="alert"`).

### T-INVITE-ONB-STEP2 — «Шаг 2 из 2»
```
Шаг 2 из 2
Интересы
Восемь направлений под твои ценности. Нажми, чтобы убрать или вернуть; остальные покажу реже.
```
Под кнопками: `Все направления можно поправить позже в разделе «Профиль».` Кнопки: `← Назад` · `Показать подборку →`; строка бюджета — по `T-ONB-BUDGET`.

### T-INVITE-ONB-SAVE-FAIL — не удалось сохранить в онбординге
```
Не получилось сохранить, попробуй ещё раз.
```

### T-INVITE-JOINED — «Имя идёт с тобой»
Строка под событием в «Плане» пригласившего и тост при первом открытии приложения после принятия. Только на «иду».
```
{Имя} идёт с тобой: «{title}», {суббота, 24 окт}.
```
Если друг скрыл имя: `Друг идёт с тобой: …`.

### T-INVITE-JOINED-MANY — сводное уведомление пригласившему
Первые три друга по одному приглашению получают отдельный `T-INVITE-JOINED`; начиная с четвёртого уведомление не уходит сразу: раз в день после утреннего плана приходит одно сообщение на приглашение, без имён (в «Плане», той же строкой):
```
Ещё {n} {друг идёт / друга идут / друзей идут} с тобой: «{title}», {суббота, 24 окт}.
```
Если за день пришёл один новый друг сверх трёх, всё равно используется эта форма (`Ещё 1 друг идёт с тобой: …`).

### T-INVITE-TOGETHER — подпись в плане
Где: `T-PLAN-HEAD`, `T-PLAN-CARD`, `T-PLAN-TODAY` и веб-план. Строка после времени:
```
Вдвоём с {Имя}
```
Если имя скрыто: `Вдвоём с другом`. Приглашённых несколько: `С друзьями ({n})`.

### T-INVITE-OFFER — своя подборка
Блок на экране «Вы идёте вместе», только без готового профиля:
```
Хочешь свою подборку на выходные?
Два шага: пять главных ценностей и интересы, около минуты. Дальше подборка будет приходить по четвергам.
```
Кнопки: `Давай` · `Потом`. Повтор, один раз, в приложении при первом открытии после дня события, над «Подборкой»:
```
Если понравилось, могу подбирать такие выходные каждую неделю. Два шага, около минуты.
```
Кнопки повтора: `Давай` · `Не нужно`; после «Не нужно» предложений больше нет.

### T-INVITE-LATER — «Потом»
```
Хорошо. Начать можно в любой момент в разделе «Профиль».
```

### T-INVITE-SELF — автор открыл своё приглашение
```
Это твоё приглашение. Чтобы позвать друга, нажми «Позвать друга» на карточке события.
```

### T-INVITE-PAST — событие прошло
Вместо шапки и кнопок решения. Нет профиля:
```
Это событие уже прошло, но выходные впереди. Подборку под себя можно собрать за два шага.
```
Кнопка: `Другие выходные под меня`. Есть профиль:
```
Это событие уже прошло. Подборка на ближайшие выходные ждёт в «Подборке».
```

### T-INVITE-UNPUBLISHED — событие снято
Нет профиля:
```
Это событие убрали из афиши. На ближайшие выходные есть другие: подборку под себя можно собрать за два шага.
```
Кнопка: `Другие выходные под меня`. Есть профиль:
```
Это событие убрали из афиши. Другие на ближайшие выходные ждут в «Подборке».
```

### T-INVITE-GONE — пригласивший удалил данные
Заголовок шапки вместо «Имя зовёт тебя»:
```
Тебя зовут на событие
```
Кнопки: `Иду` · `Может быть` · `Другие выходные под меня`. Слово «вместе» и подпись `T-INVITE-TOGETHER` не используются.

### T-INVITE-BAD — код не найден
```
Эта ссылка не работает. Подборку на выходные можно собрать за два шага.
```
Кнопка: `Другие выходные под меня`.

### T-REF-ASK — просьба о рекомендации
Где: вкладка «Входящие», под строкой оценки 4–5, не чаще раза в две недели.
```
Рад, что зашло. Если есть кому посоветовать такие выходные, вот ссылка.
```
Кнопка: `Поделиться` (системное окно с текстом `T-REF-SHARE`; запасной вариант `Скопировать`).

### T-REF-SHARE — текст рекомендации
Простой текст, первое лицо, первая строка без названия сервиса, не длиннее 300 знаков вместе со ссылкой:
```
Пользуюсь сервисом, который каждый четверг присылает 5–7 событий на выходные и объясняет, почему они мне подходят. Настройка занимает минуту. Попробуй: {ссылка}
```
Ссылка: `<домен>/?ref=<код>`.

### T-RATE-LOW — оценка 1–2
Где: вкладка «Входящие», под строкой оценки.
Чем плох прежний порядок: после низкой оценки не было вопроса, что пошло не так.
```
Жаль, что не зашло. Что было не так? Это необязательно.
```
Кнопки те же, что `T-REASONS`: `Не моё` · `Дорого` · `Далеко` · `Уже был` / `Ещё…`. Тост — «Учту.». Просьба о рекомендации после 1–2 не показывается.

### T-SETUP-NAME — переключатель «Показывать имя друзьям»
Где: страница «Профиль», блок «Параметры». Переключатель (`role="switch"`, `aria-checked`), подпись и пояснение:
```
Показывать имя друзьям
Друг, которого ты позвал, увидит на странице события «{Имя} зовёт тебя». Если выключить, будет «Друг зовёт тебя».
```
Состояния в тексте: `Показывается` / `Скрыто`. По умолчанию включён. Отметка в плане пригласившего действуют так же (`T-INVITE-JOINED`, `T-INVITE-TOGETHER`).

### T-APP-NAME — имя приложения
`Успею`. Пишется с заглавной, без кавычек в интерфейсе; в тексте документов — «Успею». Имя от первого лица: то, что человек думает в сценарии «освободился вечер». Вторичная ассоциация — «ничего не упущу»; имя не описывает категорию (нет «афиши» и «гида») и не совпадает с KudaGo, Афишей, Яндекс Афишей, Timepad, Kassir. Запасные варианты и выбор — отчёт дизайнера и `DESIGN.md`, «Имя и слоган». В манифесте: `name: Успею`, `short_name: Успею`; в статус-баре и заголовке вкладки браузера — `Успею`.

```
Ничего интересного мимо тебя не пройдёт
```
Одна строка, на «ты», без точки и восклицания. Стоит под именем на первом экране и на странице установки; внутри вкладок не повторяется.

## 11. Приложение, версия 2: три вкладки, лента, план, профили

Экраны — `FLOW-APP.md`, компоненты — `DESIGN.md`. Простой текст приложения; служебные строки набираются капслоком моноширинным шрифтом и здесь так и записаны. Правило версии 2: ни одного объяснительного текста — только названия, значения и действия; исключения названы отдельно.

### T-NAV — нижняя навигация
Подписи вкладок: `Лента` · `План` · `Профиль` (вкладка «Рекомендации» в документах — это подпись «Лента»: до 7 знаков, чтобы три подписи не переносились на 375 px). Бейдж на «Плане» — точка без текста; скринридеру `aria-label`: `План, есть неотмеченные`.

### T-DAYS — выбор дня
Чипы: `Сегодня` · `Завтра` · `Послезавтра` · `Неделя`; кнопка-иконка календаря с подписью для скринридера `Выбрать дату`. Заголовок вкладки повторяет выбранный день: `Сегодня`, `Завтра`, `Сб, 25 окт`, `Неделя`.

### T-SEGMENT — направление
`Досуг` · `Дело` · `Всё`.

### T-FEED-CARD — карточка-билет
Служебные строки (капслок): бейдж `УСПЕВАЕШЬ`; счётчик `{n} / {всего}`; строка дня `СЕГОДНЯ · СБ 24 ОКТ`, `ЗАВТРА · ВС 25 ОКТ`, на «Неделе» `ВТ 27 ОКТ`; интервал `19:00–23:00`; подвал `ОТ {цена} ₽ · {направление}` или `БЕСПЛАТНО · {направление}`; без цены — только направление. Число-герой — время начала `19:00`. Текст: название события, `{площадка} · м. {метро}`. Ссылка: `Подробнее`. Кнопки: `Не моё` · `Иду`. Стампы при перетаскивании: `ИДУ`, `НЕ МОЁ`.

### T-FEED-GOING — лист после «Иду»
```
В плане
«{title}», {сегодня, 19:00}, {площадка}.
```
Кнопки: `К билетам` (ссылка на источник) · `Календарь` (Google Календарь · Outlook · .ics) · `Позвать друга` · `Дальше`. Если у события нет ссылки на источник, кнопки `К билетам` нет.

### T-FEED-UNDO — тост после «Не моё»
```
Убрал.
```
Кнопка: `Отменить` (5 с).

### T-FEED-END — все карточки дня просмотрены
```
На сегодня всё
```
Кнопка: `Завтра`. На «Завтра» и «Послезавтра» заголовок `На этот день всё`, кнопка следующего дня; на «Неделе» — `На неделю всё`, кнопка `Календарь`.

### T-FEED-EMPTY — ничего не подошло
```
Пока ничего
```
Кнопки: `Всё` (если выбрано направление) · `Завтра`.

### T-FEED-LATE — сегодня уже не успеть
```
Сегодня уже поздно
```
Кнопка: `Завтра`.

### T-EVENT — страница события
Кнопки: `Иду` (закреплена), `К билетам`, после «Иду» — `Позвать друга`. Служебные строки как на карточке. Событие прошло: строка `ПРОШЛО`, кнопки решений скрыты.

### T-PLAN2 — вкладка «План»
Заголовки секций: `Прошли`, `Сегодня`, `Завтра`, дальше `Сб, 25 окт`. Метки записей (капслок): `МОЖЕТ БЫТЬ`, `ВДВОЁМ С {ИМЯ}`, `С ДРУЗЬЯМИ ({n})`, `СНЯТО` (событие убрано из афиши). Конфликт: `Пересекается с «{другое}»`. Кнопки записи: `Календарь` · `К билетам` · `Позвать друга` · `Убрать`; у «может быть» — `Иду`.

### T-PLAN2-PAST — отметка прошедшего
Чипы: `Сходил` · `Не сходил`. После `Сходил` — ряд `1 ★` … `5 ★` (скринридеру `1 звезда` … `5 звёзд`), выбранная с `● `. Тосты: `Отмечено.`, `Оценка {n} из 5.`, `Оценка изменена: {n} из 5.`

### T-PLAN2-EMPTY — план пуст
```
Пока пусто
```
Кнопка: `Рекомендации`.

### T-PROFILE2-SWITCH — переключатель профилей
Чипы: `я` · `{имя}` · `+`. В листе: список профилей с `● ` у активного, последняя строка `+ Новый профиль`. Имя профиля по умолчанию при первом входе — `я`.

### T-PROFILE2-NEW — новый профиль
Лист: заголовок `Новый профиль`, поле `Имя` (подсказка в поле `Мама`), выбор `Кто это`: `Я` · `Родитель` · `Ребёнок` · `Другой`, кнопка `Дальше` → Шаг 1 из 2 для этого профиля (заголовок шага дополняется именем: `Что важно для {имя}`). Ошибка пустого имени: `Напиши имя.`

### T-PROFILE2 — секции профиля
Заголовки: `Ценности` (счётчик `5 / 5`), `Направления` (значения ползунка `НЕ ПОКАЗЫВАТЬ` · `ИНОГДА` · `ИНТЕРЕСНО` · `ГЛАВНОЕ`), `Бюджет` (`Не важно` · `до 1 000 ₽` · `до 2 500 ₽` · `до 5 000 ₽`), `Время` (`Утро` · `День` · `Вечер` · `Ночь`), `На дорогу` (значение `{n} МИН`), `Что я о тебе узнал`, `Показывать имя друзьям` (`role="switch"`, состояния `Показывается` / `Скрыто`), `Почта · скоро` (`T-EMAIL-SOON`), `Установить на экран` (`T-INSTALL-*`), `Удалить мои данные` (`T-APP-DELETE`). Тост сохранения не показывается; ошибка сети — `T-APP-OFFLINE-ACTION`.

### T-LEARNED / T-LEARNED-EMPTY — «Что я о тебе узнал»
Чипы: `+ {Джаз}` (вес растёт), `− {Вечеринки}` (вес падает). Лист по нажатию: `Больше` · `Меньше` · `Сбросить`. Пусто (`T-LEARNED-EMPTY`):
```
Пока ничего. Отмечай «Иду» и «Сходил».
```

### T-PROFILE2-DELETE — удалить профиль (не «я»)
Лист: `Удалить профиль «{имя}»? Его ответы и решения исчезнут.` Кнопки: `Удалить` · `Оставить`.

### T-APP-ERROR — ошибка загрузки
```
Не загрузилось
```
Кнопка: `Повторить`.

### T-APP-OFFLINE — нет связи (служебная полоса)
```
НЕТ СВЯЗИ
```
Тост при действии без связи (`T-APP-OFFLINE-ACTION`): `Нет связи. Отправлю, когда появится.`
