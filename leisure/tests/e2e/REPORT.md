## Дефекты

### Высокая

**1. «Дело» всегда пусто на настоящих данных.** Деловые категории каталога (`Конференции и форумы`, `Бизнес-завтраки`, `Закрытые клубы`, `Образование для управленцев`) отсутствуют в seed: у 177 событий категории только `Нетривиальное`, `ИИ и технологии`, `Управление и стратегия`, `Предприниматели и клубы` и др. Поэтому «Дело» на сегодня, завтра и неделю — «Пока ничего» + «Всё», а 39 деловых по смыслу событий лежат в «Досуге». Шаг 2 онбординга при этом предлагает четыре деловых направления, под которые событий нет. Шаги: онбординг → «Показать рекомендации» → «Неделя» → «Дело». Скриншоты: `s3-week-biz-ui-*`, `s3-today-business-*`, `s1-step2-*`.

**2. Профиль «Ребёнок» получает взрослую ленту.** Для `kind=child` (ценности Веселье, Азарт, Природа, Семья, Удовольствие) в первой тридцатке: «Urban Winery», «Компаньон — винный бар», «Бал Сатаны», бурлеск-вечеринка, «Probka Wines», рейв театра теней. `params.kids=false`, `adults30=true`, у всех 177 событий `audience_kids=false`, возрастного фильтра нет. Шаги: «Профиль» → «Новый профиль» → Ребёнок → шаги 1/2 → лента (`s5-child-feed-*`).

### Средняя

**3. Шаг 1 «Что для тебя важно» предзаполнен чужими пятью ценностями** (Развитие, Творчество, Дружба, Наставничество, Забота — демо-веса из API по умолчанию), счётчик сразу «5 / 5», остальные 14 чипов неактивны (контраст 2,8:1) и не реагируют. Авто-переход на пятом выборе не срабатывает, пока не снять отметки: свои пять ценностей = 10 нажатий, весь вход 14 вместо 9–12. Те же предзаполненные пять получает и профиль ребёнка. Шаги: приветствие → галочка → «Начать» (`s1-step1-*`, `s5-child-step1-*`).

**4. Карточка в «Прошли» прыгает после «Сходил».** Список пересортировывается: карточка, на которой нажали «Сходил», уходит вниз, а звёзды открываются у неё же, но уже на втором месте; на прежнем месте оказывается другое событие с теми же кнопками. Палец, идущий к ★, попадает не туда. Шаги: два вчерашних «иду» → «План» → «Сходил» на верхнем (`s4-plan-before-*` → `s4-plan-rated5-*`).

**5. Длинное слово без пробелов ломает ширину.** Название со словом из 102 букв: страница события `/e/<slug>` шириной 1352 px, «План» — 1012 px (горизонтальный скролл, страница уменьшается на телефоне). В ленте карточка обрезает слово. В `globals.css` у заголовков события и плана нет `overflow-wrap`. Скриншоты: `s7-long-event-*`, `s7-long-plan-*`. (Тестовое событие добавлено в БД на время прогона и удалено.)

**6. Выбранный день «Неделя» и дата из календаря не видны.** Полоса дней уходит под кнопку календаря, выбранный чип скрыт под затемнением (виден только сегмент «Н»), в заголовке остаётся только «Неделя». Скриншоты: `s3-week-biz-ui-*`, `s3-calendar-*`.

**7. Текст приглашения обрезан посреди слова.** Лист «Позвать друга»: «Иду на ««Каренина. Том второй» — Егор Перегудов, Театр им. Маяковск…»: воскресенье, 25 окт, 17:00, Театр им. Вл. Маяковского, Основная сце….» — с двойными кавычками и обрывами «Маяковск…», «сце…», это сообщение уходит другу. Скриншот: `s6-invite-sheet-*`.

### Низкая

8. Вложенные кавычки «««…»»», если в названии уже есть «»: лист «В плане» и экран друга «Вы идёте вместе» (`s2-after-idu-light`, `s6-friend-done-*`).
9. Чип профиля без имени показывает аватар «Я» и рядом строчное «я» (`s1-digest-light` до ввода имени).
10. Объяснительные тексты: приветствие («Два шага, около минуты: что для тебя важно и что интересно. Регистрации нет.»); у друга после «Иду вместе» («Аня увидит, что ты идёшь. Событие в плане.», «Два шага, около минуты.»); в профиле абзац про «Показывать имя друзьям» («Друг, которого ты позвал, увидит на странице события …»). Согласие и отзыв — юридический текст, не считаю.
11. У 12 из 177 событий ссылка «К билетам» ведёт на главную сайта источника (например Еврейский музей, «Век Майи Плисецкой» → `jewish-museum.ru`).
12. «Неделя» ограничена 20 карточками, из них 14 — сегодняшние; счётчик «1 / 20» скрывает остальное: в базе на сегодня 62 события, API с `limit=100` отдаёт 46 для «Всё».
13. Двойное нажатие «Начать» и «Иду вместе» отправляет два запроса; результат верный, но кнопка не блокируется.
14. Неверный код приглашения на странице существующего события не сообщается пользователю; `/r/<битый код>` без пояснения ведёт на приветствие; для неизвестного события пишется «Эта ссылка не работает» (непоследовательно).
15. Перезагрузка на шаге 1 сбрасывает несохранённые правки к предзаполненным пяти.
16. Шрифты берутся с `fonts.googleapis.com` / `fonts.gstatic.com` при каждом открытии (внешняя зависимость; в первом прогоне `networkidle` не наступил за 30 с). Офлайн-заглушка набрана системным шрифтом с засечками, не Piazzolla (`s7-offline-*`).

Что хорошо: карточка-билет читается в обеих темах, «Не моё»/«Иду» равные по размеру, бейдж «Успеваешь» совпадает с API, цвета тёмной темы читаемы, оценки меняют ленту в нужную сторону (5★ вверх, 1★ вниз), решения между профилями не смешиваются, приглашение работает без сессии, ошибок консоли нет.

## Что не удалось проверить без живого телефона

- Системный диалог «Поделиться» (Web Share API) и реальную вставку в мессенджер: проверен только запасной вариант «Скопировать» (буфер).
- Баннер «Установить на экран» (`beforeinstallprompt`, iOS «Поделиться»), установку по HTTPS и запуск из иконки без адресной строки; проверен только валидный manifest, иконки, SW.
- Ощущение свайпа карточки (перетаскивание, стамп, haptic) на настоящем тач-экране; тестировались кнопки.
- iOS Safari и Android Chrome: безопасные зоны (чёлка, нижняя полоса), экранная клавиатура поверх полей, масштабирование при фокусе, нативный `input[type=date]`.
- Переключение системной темы на лету и яркость экрана на улице (темы проверены эмуляцией `prefers-color-scheme`).
- Поведение на нестабильной сети (потеря связи посреди «Иду», обновление SW).
- Вход по почте (SMTP не настроен, страница перехода по ссылке из письма не сделана), «Удалить мои данные» из интерфейса (аккаунты удалялись через API), блок «Что я о тебе узнал», кнопки «Убрать» и «Отменить» в листе.
- Реальные шрифты в стране с блокировкой Google Fonts.

### Новые дефекты

#### Высокая

**Н1. Колода пропускает карточки, лента заканчивается раньше времени.** После нескольких решений серверные данные ленты обновляются (из ленты пропадают решённые и подавленные обучением события), а индекс колоды не сбрасывается: счётчик идёт «11 / 20 → 12 / 20 → 13 / 19 → 14 / 14», после 14-го «Не моё» показывается «На сегодня всё», хотя события остались. Перезагрузка `/digest` тут же показывает карточки, которых пользователь ни разу не видел (в двух запусках 6 и 14 непоказанных: «Каренина. Том второй», «Дузе», «Здесь и там» Годара…). Шаги: новый профиль с любыми ценностями → «Сегодня» → «Досуг» → «Не моё» до конца → экран «На сегодня всё» → обновить страницу. Скриншоты: `p2-s3-skip-end-light.png`, `p2-s3-feed-end-light.png`; воспроизведение — `scripts/p2-skip.js`, `scripts/p2-end2.js`.

#### Средняя

**Н2. Событие с «Иду» остаётся в ленте и стоит первым, без метки; «Не моё» по нему молча снимает «Иду».** После «Иду» на «Фаусте» и перехода в «Неделю» или обновления «Сегодня» первой снова идёт та же карточка с кнопками «Не моё / Иду» и без отметки «в плане» (API отдаёт `decision: иду`). Нажатие «Не моё» перезаписывает решение, и событие исчезает из «Плана» (в моём прогоне план оказался пуст, пока я не нашёл причину). Шаги: «Иду» на первой карточке → «Дальше» → обновить `/digest?day=week` → первая карточка та же → «Не моё» → «План» пуст. Скриншот: `p2-dup-card-light.png`, `p2-dup-faust-light.png`; `scripts/p2-dup.js`, `p2-dup2.js`.

**Н3. «Отменить» после «Иду» недоступно, пока открыт лист «В плане».** Тост «В плане · Отменить» лежит под модальным листом: нажатие перехватывает лист (проверка по `elementFromPoint`), в листе кнопки «Отменить» нет. После «Дальше» тост ещё виден, но из пяти секунд остаётся меньше. Скриншоты: `p2-s8-sheet-undo-light.png`, `p2-s8-toast-after-close-light.png`.

#### Низкая

- **Н4.** Шаг 2 профиля «Ребёнок» предлагает (и предотмечает) «Вечеринки» и «Винные бары», которые в его ленте скрыты (`p2-s5-child-step2-*`).
- **Н5.** Лента ребёнка «Всё» на неделю содержит «Конференции и форумы», «Закрытые клубы», «Образование для управленцев»; первая пятёрка недели — взрослый театр и концерты. Положительного фильтра по возрасту нет (`audience_kids=false` у всех 177 событий).
- **Н6.** Профиль без имени: в строке профилей на экране «Профиль» пустой чёрный кружок «●» без подписи, пустая строка в листе «Профиль» (аватар «Я», точка, справа «Я»), пустое поле имени (`p2-s6-switcher-noname-*`, `p2-s6-profile-noname-*`). На экране «Профиль» имя профиля теперь показано дважды: чип в шапке и строка профилей под заголовком.
- **Н7.** Ссылка приглашения строится API по его `WEB_BASE_URL` (по умолчанию `http://localhost:3000`), адрес запроса веба для этого не используется; README веба обещает «без неё берётся из заголовков» — для приглашений это не так. При запуске на другом порту ссылка друга ведёт в никуда (стенд пришлось перезапустить с `WEB_BASE_URL`).
- **Н8.** В политике остались заглушки «[ЮРЛИЦО или ИП, ОГРН/ОГРНИП, адрес]», «[email]» (`/policy`).
