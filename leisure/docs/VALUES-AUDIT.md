# Аудит ценностей: покрывают ли 13 ценностей то, ради чего люди ходят на события

Нынешний список из 13 ценностей взят из личной практики владельца продукта. Для одного человека он точен,
для продукта на тысячи людей нужна проверка: есть ли события, которые не ложатся ни на одну из них.

## 1. Что показывают данные

Сколько из 177 событий базы сильно задевают каждую ценность (вес тега не ниже 0.6):

| Ценность | Событий | Ценность | Событий |
|---|---|---|---|
| Творчество | 91 | Свобода | **0** |
| Развитие | 83 | Семья | **0** |
| Красота/эстетика | 83 | Забота | **0** |
| Исследования | 77 | Сохранение традиций | **0** |
| Инновации/новизна | 70 | Наставничество | 5 |
| Единство/Дружба | 61 | Природа | 9 |
| Здоровье | 16 | | |

Четыре ценности не задевает ни одно событие, две задеты почти случайно. Это значит, что на первом экране
человек выбирает «Семья» или «Свобода» в пятёрку главных, а подборка на это никак не реагирует.

Категории с самым слабым покрытием: матчи (1.7 ценности на событие), своими руками (2.0), волейбол (2.1),
предприниматели (2.2), винные бары (2.7). У 12 событий одна ценность или ни одной: драм-н-бейс до утра,
дерби Суперлиги, дегустация вин, утро основателей. Их реальный мотив в списке отсутствует, и скоринг
держит их только на суррогатах: «шумно» даёт 0.3 к Дружбе, новизна и эстетика.

## 2. Чего нет в списке

Мотивы досуга, под которые события есть, а ценности нет:

| Мотив | Примеры событий | Чем сейчас подменяется |
|---|---|---|
| **Удовольствие** (вкус, комфорт, нега) | винные бары, дегустации, ужины шефа, спа | эстетика, новизна |
| **Веселье и игра** | вечеринки, квизы, стендап, караоке, настолки | «шумно» → Дружба 0.3 |
| **Азарт и соревнование** | матчи, турниры, любительская лига, киберспорт | новизна, «шумно» |
| **Покой и восстановление** | баня, тихие прогулки, медитация, ретрит, чтение | ничем, таких событий в базе почти нет |
| **Близость** (пара, романтика) | свидание, ужин вдвоём, танго для пар | ничем; «вдвоём» только служебный тег компании |
| **Смысл** (духовность, философия) | лекции о смысле, храмы, философские клубы, ретриты | Исследования 0.6 через «глубоко» |
| Признание и статус | закрытые клубы, премьеры, гала | нетворкинг |
| Приключение и риск | картинг, квесты, полёты, зимнее плавание | новизна |
| Вклад и служение | волонтёрство, благотворительные забеги | должна быть Забота, но тега нет ни у одного события |
| Ностальгия | ретро-вечеринки, кино 80-х, пластинки | Сохранение традиций, но тега нет |

Первые шесть — самостоятельные мотивы с заметной долей событий. Последние четыре можно закрыть тегами
к уже существующим ценностям.

## 3. Предложение

**Расширить список с 13 до 19 ценностей**, не меняя исходные (чтобы паритет с прототипом и профили
владельца не сломались), и добавить теги под них. На экране онбординга показывать карточки группами из
четырёх кластеров, чтобы 19 не читались как стена:

| Кластер | Ценности |
|---|---|
| Познание | Развитие, Исследования, Инновации/новизна, Творчество |
| Люди | Единство/Дружба, Наставничество, Забота, Семья, **Близость** |
| Тело и чувства | Здоровье, Красота/эстетика, Природа, **Удовольствие**, **Покой**, **Азарт**, **Веселье** |
| Смысл | Свобода, Сохранение традиций, **Смысл** |

Выбор по-прежнему «пять главных», остальным — «важно / не очень». Шесть новых ценностей выделены жирным.

**Новые теги и их связь с ценностями** (в формате `catalog.VALUE_MAP`):

```
веселье → Веселье 1.0, Единство/Дружба .3      игра → Веселье .8, Азарт .5
юмор → Веселье 1.0                             вкус → Удовольствие 1.0
комфорт → Удовольствие .8                      азарт → Азарт 1.0
болеть → Азарт .8, Единство/Дружба .5          соревнование → Азарт 1.0, Здоровье .3
покой → Покой 1.0                              тишина → Покой .8, Красота/эстетика .3
романтика → Близость 1.0                       смысл → Смысл 1.0, Исследования .4
духовно → Смысл 1.0                            приключение → Инновации/новизна .7, Азарт .5
статус → Единство/Дружба .3, Наставничество .3 волонтёрство → Забота 1.0, Единство/Дружба .5
ностальгия → Сохранение традиций .7, Веселье .3
```

Теги под старые «пустые» ценности уже существуют (`семья`, `дети`, `свобода`, `ритуал`, `забота`,
`наставничество`), но нормализатор прототипа их не ставил. Это вторая половина проблемы: не только список
ценностей узок, но и разметка событий не использует то, что есть.

| Где | Что | Объём |

| бот и макет онбординга | карточки ценностей группами, 19 вместо 13 | полдня |

Сначала разметка событий, потом экран: иначе человек выберет «Покой», а событий под него не окажется.

## 5. Решения владельца продукта

1. Утвердить шесть новых ценностей и их названия для карточек: Удовольствие, Веселье, Азарт, Покой,
   Близость, Смысл. Названия должны читаться за секунду и не стыдить при выборе.
2. Оставить ли «Признание и статус» отдельной ценностью. В списке выше он сведён к тегу: выбирать такое на
   первом экране многие не захотят, а теги к событиям поставить можно.
3. Переразметка seed: делать сразу (один прогон нормализатора по 177 событиям) или по мере обновления базы.
