# Коллекторы: статус источников

Источники — из `seed/sources.json`. Интерфейс один: модуль `collectors/<name>.py`, класс-наследник `Collector`,
метод `collect(city, date_from, date_to) -> list[RawEvent]`, регистрация декоратором `@register`.
Порядок предпочтения: API, затем RSS, затем разметка. Ошибки источника — `CollectorError` (`base.py`).

Проверки сети сделаны 2026-10-24 из окружения разработки: по одному запросу на хост, с идентифицирующим
User-Agent. Если в столбце нет слова «проверено», сведения со слов документации или предположение.

## KudaGo: что важно знать

- **robots.txt.** Для `User-agent: *` там `Disallow: /public-api`, хотя API опубликован для разработчиков
  (`docs.kudago.com`). По правилу «уважать robots.txt» коллектор по умолчанию останавливается с понятной
  ошибкой, ни одного запроса к API не делает. Снять запрет может только владелец продукта:
  `KudaGoCollector(respect_robots=False)` или `KudaGoCollector.respect_robots = False`.
- **Доступ.** Из окружения разработки `/public-api/` отвечает 403 от nginx KudaGo даже с честным User-Agent
  (`robots.txt` и `docs.kudago.com` при этом открываются). Похоже на блокировку по адресу; обход не делали.
- **Лицензия** (раздел «Лицензионное соглашение» в документации): у каждого показанного события должна быть прямая
  индексируемая ссылка на карточку первоисточника (кладём её в `RawEvent.url`), данные нельзя передавать
  третьим лицам на коммерческой основе, «kudago» нельзя использовать в названии продукта. Сверить с монетизацией (п. 9).
- **Не проверено на живом ответе:** смысл `actual_since` / `actual_until` в документации описан двусмысленно
  (начались после / закончились до), поэтому пересечение с диапазоном дополнительно проверяется у нас; значения
  дат «бессрочно» разбираются по флагам `is_endless` / `is_startless`.

## Запуск

```python
from datetime import date
from leisure.collectors import load_collectors
from leisure.collectors.base import collect_all

load_collectors()  # импортирует модули-источники, срабатывают декораторы @register
raw = collect_all("Москва", date(2026, 10, 23), date(2026, 10, 25), names=["kudago"])
```

`collect_all` не перехватывает исключения: сбой одного источника прерывает остальные, воркеру стоит ловить
`CollectorError` вокруг каждого коллектора отдельно. Счётчики запуска (страниц, получено, оставлено, вне диапазона,
пропущено, повторов) лежат в `stats` экземпляра, поэтому для отчёта вызывайте коллектор напрямую:
`c = KudaGoCollector(); raw = c.collect(...); c.stats`.
