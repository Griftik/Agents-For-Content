# Медиа для бота

`welcome.mp4` — кружок (video note) ~20 секунд для первого экрана. TODO(Евгений).

Требования Telegram к кружку: квадратное видео (например 640×640), mp4 (H.264 + AAC),
длительность до 60 секунд. Если файла нет, бот просто пропускает кружок и отправляет текст.
Бот загружает файл один раз и дальше переиспользует file_id (перезапуск — загрузит снова).
